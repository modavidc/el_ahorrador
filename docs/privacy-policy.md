# Política de privacidad de El Ahorrador

Última actualización: 27 de julio de 2026

El Ahorrador procesa en el dispositivo las imágenes compartidas por el usuario,
el texto extraído por OCR y los datos financieros que el usuario decide guardar.
Estos datos se usan exclusivamente para registrar y organizar sus gastos.

## Almacenamiento y respaldo

La base de datos local se cifra con SQLCipher y una clave protegida por el
almacén seguro del sistema. Los respaldos que exporta el usuario se cifran con
una contraseña elegida por él. El respaldo automático del sistema está
deshabilitado en Android. Desinstalar la aplicación elimina los datos locales
conforme al comportamiento del sistema operativo.

## Diagnósticos opcionales

La telemetría remota está desactivada de forma predeterminada y sólo se habilita
en compilaciones configuradas expresamente con consentimiento. No se adjuntan
texto OCR, importes, rutas, capturas de pantalla ni cuerpos de solicitudes. El
proveedor de diagnóstico es Sentry. El procesamiento OCR se realiza localmente
mediante ML Kit.

## Control del usuario

El usuario puede borrar sus registros desde la aplicación y puede exportar un
respaldo cifrado. No vendemos datos personales ni los usamos para publicidad o
seguimiento entre aplicaciones. Las solicitudes sobre privacidad deben dirigirse
al canal de soporte publicado junto con la aplicación en la tienda.

Esta política debe publicarse en una URL accesible y mantenerse alineada con las
declaraciones Data Safety de Google Play y App Privacy de Apple antes de lanzar
la aplicación.
